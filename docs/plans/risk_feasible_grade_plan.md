# 작업계획: 리스크 등급 — feasible 학생 B 완화 (사용자 제안, D-2)

> 문제: 잔여 학기 내 졸업 가능(feasible·수용량 내)인데 절대 갭(>15)이 D를 트리거해 완화해도
> C(위험)에 머묾 — S4(막학기 1과목+전부 배치)가 C. 등급은 절대 부족량이 아니라 **잔여 수용량
> 대비 진행 위험**이어야 함(2학년 갭 90 ≠ 위험).

## 변경 (risk.py 완화 게이트 1곳)

현행: `feasible ∧ grade==D ∧ gap≤capacity → C` (D만 완화)
변경: `feasible ∧ gpa≠no ∧ gap≤capacity` 이면 **갭·영역·필수·융합 트리거 기인 등급을 B로
클램프**(사유: "실현 가능한 학기별 계획 존재(잔여 수용량 내) — 계획 이행 전제 B로 완화" (B=주의 — '양호' 표현 금지, codex MUST)). 단:
- blocked(feasible=False)·수용량 초과·평점 미달 → 현행 유지(C/D)
- 졸업인증제 경고(B 트리거)는 로드맵과 무관한 별도 요건 — B 클램프와 결과 동일이라 충돌 없음
- A는 현행대로 트리거 0일 때만(이미 충족) — "계획이 남은" 학생은 최고 B(정직)
- 완화 전 원사유(reasons)는 전부 유지 — 등급만 클램프, 사유에 완화 표기 추가

## 영향 (사전 추정 — 구현 후 실측 확정)

- S4: C→**B** | S1·S2: blocked → C 유지 | S3: blocked·초과4 → D 유지(D 완화 게이트 별도 존재 — 검증 시 확인)
- 연쇄: S4 summary 캐시(facts에 리스크 포함 → 키 미스)·whatif 캐시(diff의 risk_before) →
  **S4만 재워밍업**(전체 1사이클이 간단하면 전체). demo_script·current_state의 S4 "C 완화" 표기 갱신.
- 위험: S2의 'C 완화(D→C, overflow_verified)' 경로와의 상호작용 — blocked라 새 게이트 미적용
  확인 필수. risk 점수(score)는 sev 합산 그대로(등급만 변경).
