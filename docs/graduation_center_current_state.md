## 2. 큰 그림 — 실제 워크플로우 (화면의 그래프와 동일)

```mermaid
flowchart TD
    A["① 요람 로딩<br/>(학번별 요건·카탈로그)"] --> B["② 데이터 수집<br/>(.xls 학기별 병합)"]
    B --> C["③ 코드 매칭<br/>(7자리 정확 → 동일교과목 5자리)"]
    C --> D{"④ 데이터 검증 HITL<br/>재수강 팝업·폐강 제외"}
    D --> E["⑤ 갭 계산<br/>학번 요람 + 융합 중복인정 3-way"]
    E --> F["⑥ 로드맵 배치<br/>(결정론 greedy · 제32조 상한)"]
    F --> G{"⑦ 로드맵 검증"}
    G -->|통과| H["⑧ 리스크 산정<br/>(A/B/C/D + 완화 게이트)"]
    G -->|미배치| OV["⑦′ 초과학기 시나리오<br/>(+N학기·예상 졸업·경로 검증)"] --> H
    H --> I["⑨ 요람 RAG 해설 🤖LLM<br/>(부족 항목 → chunk 인용 해설)"]
    I --> J{"⑩ 해설 검증<br/>인용 해소·수치 가드·마스킹"}
    J --> K["⑪ 컨설팅 보고서<br/>(게이지·로드맵·해설·G/Y 근거 토글)"]
```

- **LLM은 ⑨ 한 곳뿐** — 판정·계산·로드맵은 전부 결정론 노드 (같은 입력 = 같은 결과, 3회 해시 동일 검증).
- ⑦의 갈래가 그래프 토폴로지로 갈라져 학생마다 **다른 경로가 점등**됨 (feasible 학생은 ⑦′가 점선으로 남음).

## 3. 사용자가 겪는 흐름

1. **학생정보 입력** — 입학연도(적용 요람 결정)·제1전공·다전공/부전공 검색·현재/잔여 학기·계절 허용·직전학기 3.75↑·졸업 평점 충족 여부
2. **.xls 업로드** — 학기당 1파일, 여러 개 한 번에
3. **검증 테이블(HITL)** — 재수강 의심 팝업("최신만 인정할까요?"), 행별 포함/제외 토글 → 확정
4. **졸업사정 실행** — 1초 내(해설 캐시 시) 보고서:
   - 종합 판정 배지(A~D) → 영역 게이지 → 융합전공 블록(겹침·중복인정·3-way SEL·그룹) → 미이수 필수 → 로드맵 타임라인(or 부분배치+초과학기 카드) → **📖 규정 근거 해설**(요람 인용 Y 배지, 근거 약한 줄은 "※ 공식 출처 미확인") → 근거 토글(G/Y)
5. **워크플로우 그래프** — 보고서 옆에서 노드가 순서대로 점등, 분기 갈래 확인

## 4. 핵심 동작 원리

> **판정·계산 = 결정론(매번 동일) · 규정 해설 = LLM(인용 강제) · 해설은 다시 결정론이 검증.**

- **결정론 본체**: 매칭→사정→배치→리스크 전부 코드. OpenAI 키 없이도 진단·로드맵·G 근거까지 완전 동작.
- **LLM(gpt-5-mini)**: 부족 항목 2~3개에 대해 검색된 요람 chunk **만** 근거로 해설 생성. 졸업 가능/불가 판정 금지(프롬프트+검증).
- **해설 validator**: 인용 id가 실제 chunk에 해소되는지, 숫자가 chunk 원문에 있는지(진단 숫자는 진단 참조 줄에만), 학번 마스킹 — 위반 줄은 "※ 공식 출처 미확인 — 학과사무실 확인 권장" 표시. **환각이 화면에 근거인 척 못 나옴.**
- **캐시**: (모델+항목+학과+입학연도) 해시 키 — 데모 학생은 사전 warm-up되어 지연 0·완전 오프라인 동작·동일 출력.

## 6. 품질 — 어떻게 믿나

- **학사규정 부합 감사**(서브 3+codex 3): 제32조·제77조·제74조⑤ 등 조문 단위 대조 — 불일치 2건(캡 15분기·교양 50 상한) 수정, 범위외 규정(논문·등록학기 등)은 보고서 caveat로 명시.
- **검증 캠페인**: 적대적 리뷰 5라운드 → 수렴 루프 7라운드(라운드당 서브에이전트 3+codex 3, CRITICAL 0까지) → 교수 페르소나 평가 6인 → 신규코드 라운드 → 데모 시나리오 라운드(변주 3종 포함). 누적 발견·수정 ≈ 25건(슬롯 시퀀스 오인 대량미배치, credits 오염 OOM, 표면 모순 계열, 캐시 trace 거짓 '통과' 등).
- **테스트**: 201 passed (파이프라인·사정·해설 validator·API), 결정론 3회 해시 동일.
- **장애 내성**: OpenAI/Chroma 다운 → 해설 섹션만 degrade(본체 무영향), 손상 엑셀 422, 오염 입력 400, 완전 오프라인 데모 가능(캐시).
