## 데모 비트 (6분)

**S4 최계절 (3분) — happy path + 학번별 요람:**
1. (0:30) 학생정보 입력: 입학 **2022**·AI빅데이터융합경영 + 데이터사이언스 다전공, 현재 2026-1·잔여 2, **계절 허용 + 직전학기 3.75↑ 체크** → .xls **7개** 업로드
2. (0:45) 검증 테이블(HITL): 재수강 의심 팝업 1건(경영통계 — 화면에 뜨는 과목명 그대로 읽기) → "성적표에 성적이 없으니 사람이 확정 — 데이터 신뢰의 다리" → 확정
3. (1:00) 졸업사정 실행 → 보고서: **적용 요람 "2022 요람(학번 2022 기준)"** — 학번별 요람이 화면에서 작동(기초교양 8학점 기준). 미이수 필수 **딥러닝 1과목**(2025 요람 기준이면 유레카도 필수지만 2022학번이라 제외 — 연도별 필수 차이) → 로드맵이 딥러닝+융합 잔여를 2학기에 배치, feasible·C(완화). 계절·성적우수(+3)는 입력 모델로 지원(이 학생은 불필요)
4. (0:45) **규정 근거 해설** 섹션: 요람 원문 인용(Y 배지 — 페이지는 화면에 뜨는 값을 그대로 읽을 것) 달린 해설 — "보고서가 스스로 규정을 설명, 챗봇 아님". 일부 줄의 '※ 공식 출처 미확인'은 "검증기가 근거 약한 문장을 잡아 표시한 것"으로 프레이밍

**S1 김융합 (3분) — 단일 최강 장면(중복인정 캡):**
1. (0:30) 졸업반·잔여 1학기, 같은 다전공 → 실행
2. (1:00) "겹침 21학점인데 **중복인정은 12까지만** — 나머지 9는 제1전공 또는 융합 한쪽만. ChatGPT는 이 캡을 몰라 '졸업 가능'이라 합니다. 우리는 융합 9학점 부족 + **초과학기 약 1학기·예상 2027-1**까지 계산 — '약'인 이유: 개설학기 제약으로 더 늘 수 있다는 caveat가 화면에 같이 뜸" (3-way 배정 UI 한 번 클릭)
3. (0:45) 워크플로우 그래프(인라인): S4와 **다른 갈래** — 로드맵 검증 ✕ → 초과학기 시나리오 노드 점등
4. (0:45) 근거 토글: G1(요람 p.693)~G5 + Y(요람 RAG chunk) — "모든 판정에 출처"

## 예상 Q&A 카드

0. **"리스크 점수가 0인데 등급이 C인가?"** → "점수는 부족 요인 가중치 합산(100−Σ)이고 등급은 최악 트리거 기준 — 부족 요인이 많아 점수가 바닥났지만 초과학기 1학기 경로가 검증돼 D가 아니라 C입니다."
1. **"이게 에이전트인가, 계산기 아닌가?"** → "자유 LLM이 답을 쓰는 게 아니라, 검증된 데이터·요람을 도구 노드들이 처리하고 분기(HITL/blocked/초과학기/해설 검증)를 타는 bounded agent입니다. LLM은 요람 근거 해설에 제한 사용 — 환각이 위험한 계산엔 안 씁니다."
2. **"생성AI는 어디에?"** → 그래프 파란 노드. "요람 chunk만 근거로 해설을 생성하고, validator가 인용을 검증해 근거 없는 줄은 '공식 출처 미확인'으로 표시합니다."(S2~S4에서 실제 표시 사례 있음)
3. **"ChatGPT에 성적표 붙여넣으면?"** → 코드 매칭·학번별 요람·중복인정 캡·제32조 상한·재수강 제외를 일관 계산 못 함 + 매번 답이 다름. 우리는 같은 입력=같은 결과(시연 가능).
4. **"2023학번 넣으면?"** → ai_bigdata도 2022~2025 학번별 요람 실적용(기초 8↔7, 일반선택 57↔58, 필수 11↔12과목, 기초 택1 구성 차이가 실제 반영 — S3은 '2024 요람(학번 2024 기준)', S4를 2025학번으로 바꾸면 기초 7·글로벌영어 제외로 화면이 달라짐). 미래모빌리티도 2023 요람 동작.
5. **"왜 로드맵을 LLM이 안 짜나?"** → "교수님이 강조하신 출력 일관성 — 배치는 제약충족 문제라 결정론이 정답. LLM 시안은 같은 입력에 다른 답을 냈습니다. 적대 검증 13라운드로 결정론 엔진을 다졌습니다."
