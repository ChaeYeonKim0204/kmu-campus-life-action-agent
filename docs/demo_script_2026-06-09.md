## 예상 Q&A 카드

0. **"리스크 점수가 0인데 등급이 C인가?"** → "점수는 부족 요인 가중치 합산(100−Σ)이고 등급은 최악 트리거 기준 — 부족 요인이 많아 점수가 바닥났지만 초과학기 1학기 경로가 검증돼 D가 아니라 C입니다."
1. **"이게 에이전트인가, 계산기 아닌가?"** → "자유 LLM이 답을 쓰는 게 아니라, 검증된 데이터·요람을 도구 노드들이 처리하고 분기(HITL/blocked/초과학기/해설 검증)를 타는 bounded agent입니다. LLM은 요람 근거 해설에 제한 사용 — 환각이 위험한 계산엔 안 씁니다."
2. **"생성AI는 어디에?"** → 그래프 파란 노드 넷(해설·상담 추출기·갈림길 선정·총평). 특히 ③갈림길 선정: "에이전트가 보고서를 보고 이 학생의 갈림길을 스스로 골라 시뮬레이션을 돌려보고 조언 — 탈락 후보까지 사유와 함께 화면에 남습니다(검토 후 제외 토글)". "① RAG 해설 — 요람 chunk만 근거로 해설을 생성하고 validator가 인용을 검증(근거 없는 줄은 '요람 원문에서 직접 확인되지 않음'). ② 상담 매개변수 추출기 — 자연어 질문을 안전한 시뮬레이션 파라미터로 변환(Tool Calling). **졸업 판정은 RAG도 추출기도 하지 않습니다 — 검증된 졸업사정 도구가 다시 계산합니다.**"
2-1. **"왜 LLM을 더 안 썼나?"** → "교수님이 강조하신 출력 일관성 때문에 의도된 설계입니다. LLM은 비정형(자연어·규정 원문)을 다루는 두 자리에만 쓰고, 정형 계산은 전부 결정론 — HyDE 슬라이드의 '사람들은 약관 용어를 쓰지 않는다' 문제도, 검색 쿼리를 학생 자연어가 아닌 결정론 노드가 요람 용어로 생성해 구조적으로 회피했습니다."
3. **"ChatGPT에 성적표 붙여넣으면?"** → 코드 매칭·학번별 요람·중복인정 캡·제32조 상한·재수강 제외를 일관 계산 못 함 + 매번 답이 다름. 우리는 같은 입력=같은 결과(시연 가능).
