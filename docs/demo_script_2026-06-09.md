## 데모 비트 (6분)

**S4 최계절 (3분) — happy path + 제32조:**
1. (0:30) 학생정보 입력: 입학 2021·AI빅데이터융합경영 + 데이터사이언스 다전공, 현재 2026-1·잔여 2, **계절 허용 + 직전학기 3.75↑ 체크** → .xls 6개 업로드
2. (0:45) 검증 테이블(HITL): 재수강 의심 팝업 1건 → "성적표에 성적이 없으니 사람이 확정 — 데이터 신뢰의 다리" → 확정
3. (1:00) 졸업사정 실행 → 보고서: 영역 게이지·융합 21/36·**로드맵 첫 학기 19학점**(=상한18+성적우수3, 제32조가 화면에서 작동) → feasible·C(완화)
4. (0:45) **규정 근거 해설** 섹션: 요람 p.881 인용 달린 해설 — "보고서가 스스로 규정을 설명, 챗봇 아님"

**S1 김융합 (3분) — 단일 최강 장면(중복인정 캡):**

2. (1:00) "겹침 21학점인데 **중복인정은 12까지만** — 나머지 9는 제1전공 또는 융합 한쪽만. ChatGPT는 이 캡을 몰라 '졸업 가능'이라 합니다. 우리는 융합 9학점 부족 + **초과학기 1학기·예상 2027-1**까지 계산" (3-way 배정 UI 한 번 클릭)
3. (0:45) 워크플로우 그래프(인라인): S4와 **다른 갈래** — 로드맵 검증 ✕ → 초과학기 시나리오 노드 점등

## 예상 Q&A 카드

1. **"이게 에이전트인가, 계산기 아닌가?"** → "자유 LLM이 답을 쓰는 게 아니라, 검증된 데이터·요람을 도구 노드들이 처리하고 분기(HITL/blocked/초과학기/해설 검증)를 타는 bounded agent입니다. LLM은 요람 근거 해설에 제한 사용 — 환각이 위험한 계산엔 안 씁니다."
2. **"생성AI는 어디에?"** → 그래프 파란 노드. "요람 chunk만 근거로 해설을 생성하고, validator가 인용을 검증해 근거 없는 줄은 '공식 출처 미확인'으로 표시합니다."(S2~S4에서 실제 표시 사례 있음)
3. **"ChatGPT에 성적표 붙여넣으면?"** → 코드 매칭·학번별 요람·중복인정 캡·제32조 상한·재수강 제외를 일관 계산 못 함 + 매번 답이 다름. 우리는 같은 입력=같은 결과(시연 가능).
4. **"2023학번 넣으면?"** → 미래모빌리티는 2023 요람(기초8·핵심17·총136) 실적용. ai_bigdata는 데모 범위상 2025만 — 구조는 연도 데이터 추가만으로 확장.
5. **"왜 로드맵을 LLM이 안 짜나?"** → "교수님이 강조하신 출력 일관성 — 배치는 제약충족 문제라 결정론이 정답. LLM 시안은 같은 입력에 다른 답을 냈습니다. 적대 검증 13라운드로 결정론 엔진을 다졌습니다."
